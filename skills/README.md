# Base Screen 宿主 Skill 模板

本目录包含用于生成宿主专属 AI Skill 的模板工具：

- **create-base-screen-host-skill/** - 生成大屏设计 Skill
- **create-base-screen-host-material-skill/** - 生成物料创作 Skill  
- **manage-base-screen-host-skills/** - 宿主接入与管理运维 Skill
- **shared/** - 共享工具与模板

## 使用方法

这些 Skill 由 AGENTS.md 中的指令调用，用于：
- **仪表盘创建**：生成宿主专属的大屏设计 Skill
- **物料创建**：生成宿主专属的物料创作 Skill
- **宿主接入**：首次接入、刷新快照、漂移诊断

详见各目录内的 SKILL.md 文件。
