# ADR-0088: Designer 工作台顶栏菜单栏与视觉基座

> 状态：已接受
> 日期：2026-10-12
> 性质：记录工作台 chrome 结构重排与视觉基座整体替换的现行决策（自 OpenDesign 工作台原型逐批移植的第一批）
> 关联：[ADR-0024](./ADR-0024-designer-public-style-tokens.md)、[ADR-0027](./ADR-0027-lightweight-designer-foundation-host-processing.md)、[ADR-0079](./ADR-0079-designer-workbench-shell-and-chrome.md)、[Designer 工作台设计移植 Spec](../specs/designer-workspace-design-port/spec.md)

## 背景

Designer 工作台的界面此前经历了 DataV 启发的一轮重做（见 ADR-0079 与其吸收记录），顶栏全局菜单收纳在「更多」子菜单里，视觉基座为深色优先的蓝灰体系。其后在独立设计工程（OpenDesign）中对整个工作台页面做出了完整重设计并以可运行 HTML 原型收敛：Vercel 设计体系、浅色优先双主题、顶层菜单栏、以及配套的表单控件与色板契约。该原型就是本项目设计器页面的目标设计，**逐批替代**现有工作台 UI；本 ADR 记录第一批（结构重排 + 视觉基座）的长期决策。

替换发生在视觉与布局层，不发生在功能层：引擎能力集合不变，禁用语义（宿主未接入的快照/保存/发布等）原样保留，只是改走新视觉。

## 决策

### 1. 顶层菜单栏（公共契约：`data-menu-toggle` / `data-menu` id；内部实现：布局与样式）

文件/编辑/视图/工具从「更多」子菜单提升为顶栏内的顶层菜单栏，四个触发器与四个面板沿既有的 `data-menu-toggle` → `data-menu` id 配对机制工作，`data-menu-action` 全集（含编辑菜单的排列/图层子菜单）保持不变，宿主与工具链原先按 id 触发菜单的能力零破坏。「更多」按钮与其面板删除。键盘左右键循环限定在同一父容器内的触发器（菜单栏内四者互切，状态栏缩放菜单保持自身）。

### 2. 工作区第二层与状态栏（内部实现）

顶部只放项目、全局菜单与交付操作；工作模式（设计/蓝图）以居中分段控件独立成组，组件工具、撤销重做与缩放归工作区 40px 列头带，顶部不提供插入菜单。状态栏画布尺寸并入右侧指标组（尺寸 → 吸附/原生事件开关 → 缩放预设），左段保留工具/选中信息/项目状态/修订。工作区工具栏缩放簇新增「缩放至适应」入口，缩放读数本身可点击复位（复用 `zoom-fit` / `zoom-reset` 操作）。

### 3. 视觉基座整体替换为原型的 Vercel 令牌体系（公共契约：Token 名称与覆盖面不变）

`designer-tokens.css` 重建为原型的令牌值：浅色缺省、`:host([theme="dark"])` 为黑夜覆盖、`:host([theme="light"])` 显式钉浅色；34 个 `--base-screen-designer-*` 公共 Token 的名称、覆盖面与宿主覆盖语义全部不变（值重定义）。对比度契约（R2 用例）消费的 Token 以可解析字面量烘焙，其余保留 color-mix 派生。两处对原型原值的偏离由引擎已接受的对比度契约（语义色与其低强调 surface ≥ 3:1）逼出，配方沿用设计要求自身「语义色向 --fg 收一档」的做法：浅色 success 收 8%、warning 收 30%（亮黄在浅底物理上无法达标）。

### 4. 默认主题翻转为浅色（宿主可见行为变化）

`:host` 缺省即浅色（原为深色）。宿主设置 `theme="dark"` 可复位到黑夜；主题切换按钮写同一属性。该翻转按 minor 变更发布。

### 5. 几何与控件档（内部实现，除注明外）

48px 顶栏、40px 列头（`--designer-column-header-height`，工具栏与左右 tab 条共享）、30px 状态栏、22px 标尺（`--designer-ruler-size`）、顶栏图标/菜单触发器与工作区工具栏按钮 28px、发布按钮为反转实底 CTA（白天黑底白字、黑夜白底黑字）。引擎保留的真实能力入口（吸附/原生事件开关、缩放预设菜单、面板折叠、错误控制台）不缩减，均按新体系重绘。

### 6. 命令面板快捷键 Ctrl/Cmd+K（公共契约：行为变化，记入 changeset）

命令面板触发器与面板内提示改用 Ctrl/Cmd+K（替换裸 `/`）；`/` 仍是面板查询里「图层」的前缀。帮助对话框与菜单内 kbd 提示随实际绑定显示。

### 7. 顶栏样式的单一维护点（内部实现）

`designer-workbench-blueprint-toolbar.css` 是顶栏样式的历史重复副本（与 `designer-workbench-topbar.css` 逐块重复且已漂移）；本次把顶栏样式（含图标按钮、徽标与响应式收缩容器查询）收敛回 `designer-workbench-topbar.css` 单点维护，前者退化为层序占位。顶栏菜单采纳 Vercel 的「阴影即描边」收边（`--designer-elev-ring`），菜单悬停保持中性（蓝色只留给编辑与焦点）。

## 非目标

- 不引入前端框架；引擎 chrome 继续是原生 TypeScript + Shadow DOM 实现。
- 不动任何 packages 公共 API、包清单与依赖边界；`check:api` 无变化。
- 不伪造引擎无能力背书的 UI（快照/保存/发布保持现状禁用语义；原型的「模板/图表包」宿主面板演示不落地）。
- 表单控件体系、检查器与面板内部、画布覆盖层与引擎独有面（蓝图/数据工作台/错误控制台/对话框）的替换在后续批次，见 Spec。

## 后果

- 宿主默认观感从深色变为浅色；需要维持旧观感的宿主显式钉 `theme="dark"`（一行属性）。
- `ADR-0079` 非目标「不改变顶栏布局、保存状态徽标、状态栏或菜单行为」一项由本 ADR 取代，不再有效；ADR-0079 其余条款（左栏信息架构、折叠与宽度写回、原生事件开关、`previewHandler`、宿主分组 slot 协议）不受影响。
- 对比度、样式原子性与裸色约束继续由 `scripts/check-designer-styles.mjs` 与引擎单测看住；本批新增的令牌全部登记，未解析引用会失败关闭。
