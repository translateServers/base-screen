# ADR-0057：调色板切换模式继承单色色系

> 状态：已接受
> 日期：2026-08-16
> 关联：[ADR-0050](./ADR-0050-unified-color-palette-control.md)、
> [ADR-0051](./ADR-0051-unified-color-palette-replaces-color-input.md)

## 1. 背景

统一三段式调色板（ADR-0050/0051）在单色模式选好颜色后切换到线性/径向渐变模式时，
色标保持内置默认（`#000000 → #ffffff`），呈现与作者所选颜色无关的黑白渐变，
破坏「先选单色、再定渐变」的常见作者路径，本地作者体验与轻量基座定位
（ADR-0027：轻量不降本地作者体验）不符。用户反馈（2026-08-16）：
切换其他模式时应公用第一个单色的色系。

## 2. 决策

1. **切换派生**：从单色模式切换到渐变模式（线性/径向）时，若当前色标为未定制的
   内置默认（恰好 2 个色标：`#000000` 0% / `#ffffff` 100%），SHALL 按单色色系
   派生色标——起点 = 单色，终点 = 同一色系提亮（向白混合 45%）；提亮与起点
   无区分度时（起色接近纯白）改为向黑加深 35%。派生保证渐变首帧与单色同色系。
   透明/不可解析单色不派生（保持默认色标）。

2. **保留自定义**：已定制的渐变色标（非默认）在模式往返切换中 SHALL 原样保留，
   不覆盖作者意图；作者以「曾经修改过色标」作为色系跟随的退出条件。

3. **派生边界**：派生只发生在交互切换路径（`designer-color-palette-dom` 的
   mode change handler）；文档值本身就是渐变的解析路径不受影响；线性↔径向
   互切保留色标与几何参数。

4. **契约不变**：字段值格式仍为色值或规范化 CSS 渐变字符串（线性
   `linear-gradient(<angle>deg, <color> <pos>%, …)` / 径向
   `radial-gradient(circle at <x>% <y>%, …)`）；序列化、ScreenDocument、
   Material Manifest、Renderer 零变化，仅 Designer 控件交互行为增强。

## 3. 非目标

- 渐变预设色板/推荐色板、HSL 色相算法强制、派生比例可配置化。
- 改变色标增删、位置编辑、草稿缓存与序列化契约（ADR-0050 既定语义）。

## 4. 结果

- 单色 → 渐变切换首帧即与单色同色系（如 `#ff0000` → `#ff0000 → #ff7373`），
  本地作者体验提升；自定义色标不受扰动。
- 公共契约零变化；验收由调色板 DOM 聚焦单测与真实 browser harness 断言覆盖。
