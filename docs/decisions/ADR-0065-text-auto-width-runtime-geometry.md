# ADR-0065：文本自适应宽度与运行时几何

> 状态：已接受
> 日期：2026-08-31
> 关联：[ADR-0027](./ADR-0027-lightweight-designer-foundation-host-processing.md)、[ADR-0047](./ADR-0047-text-material-typography.md)、[ADR-0052](./ADR-0052-designer-canvas-text-editing.md)

## 背景

官方文本既可显示静态内容，也可显示宿主资源返回的数据。标签需要随实际内容撑宽，但字体排版和
数据结果属于当前渲染环境；把每次测量结果写回文档会制造脏状态、历史和保存冲突。设计器的选择、
命中与布局计算又必须与屏幕上的文字保持一致，不能继续使用固定宽度作为实际边界。

## 决策

1. 仅 `base.text` 声明可选布尔属性 `props.autoWidth`，默认关闭。缺失保持固定模式，不迁移旧文档。
   开关复用声明式 Manifest 属性控件，不增加物料 ABI、公共方法、事件、包或依赖。
2. 开启时物料使用 `width: max-content` 与 `white-space: pre`，保留空格和手动换行，以最长一行
   决定宽度，不自动折行。宽度限制为既有尺寸范围 `1..1000000`；位置、高度与画布裁剪规则不变。
   Designer、直接预览与 Viewer 复用同一物料渲染行为，不异步加载字体来测量宽度。
3. canonical `size.width` 始终为数值，保存固定模式宽度及不可测量时的备用值。测量值只存于当前
   Designer 实例的内部尺寸控制器，由一次同步布局读取与一个共享 `ResizeObserver` 更新。读取
   未经缩放、旋转的本地 CSS 尺寸，不将视口矩形当作原始宽度。
4. Engine 向属性面板、选择框、命中、框选、吸附、对齐、分布、编组与变换提供只读文档几何投影。
   投影不得传入 Renderer、替换文档、保存、导出或复制；这些路径始终消费 canonical 文档。派生
   编组边界可在用户编辑事务中读取该投影，但不得把文本的测量宽度连同整份投影写入文档。
5. 属性面板、`W` 输入和手势实际改变文本宽度时，在同一 Core transaction 内写入新宽度并关闭
   自适应；多选及编组缩放逐个处理未锁定成员。只改高度保留原固定宽度，移动和旋转保留开关。
   用户主动关闭开关时固定为当前显示宽度。取消手势不写文档；撤销、重做沿用既有历史。
6. 手势期间冻结几何基准，结束或取消后再同步最新测量。资源刷新只更新渲染与几何，不触发文档
   change、脏状态或历史。`W` 输入中的未编辑轴随测量更新，用户正在输入的草稿保持不变。
7. 双击编辑层同样使用内容宽度，并保留位置、高度、旋转与翻转；提交只产生一条内容历史，取消
   恢复原显示。隐藏元素保留最近有效测量，首次不可测量使用文档值，重新显示后同步；组件移除、
   文档切换及实例卸载时清理观察和缓存。

## 结果

文本的数据与排版变化能即时更新可见几何，文档仍然是 JSON-safe 的显式作者配置。不同环境可按
各自字体排版重新计算宽度，保存和复制不依赖当前浏览器测量。宿主通过原始 `executeCommand` 或
`executeTransaction` 设置配置时，仍明确提供 canonical patch；运行时投影不成为公共编辑协议。

该能力不覆盖图片、自定义物料、自适应高度或父容器填充。验证包含尺寸投影、退出自适应、单次
历史、取消与生命周期单元测试，以及真实浏览器中的排版、动态数据、编辑、几何和 Viewer 一致性。
