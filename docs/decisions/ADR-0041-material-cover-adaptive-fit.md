# ADR-0041：物料封面自适应适配（小图/异形图不放大不裁切）

> 状态：已接受
> 日期：2026-08-16
> 关联：[ADR-0040](./ADR-0040-material-manifest-cover.md)、[ADR-0034](./ADR-0034-designer-material-library-visual-hierarchy.md)、[ADR-0027](./ADR-0027-lightweight-designer-foundation-host-processing.md)

## 1. 背景

ADR-0040 让物料库卡片渲染宿主提供的封面 URL，统一按 `object-fit: cover` 铺满固定 16:10 缩略图区。
真实宿主（xjdatahub 素材图片物料）把**素材原图**直接作为封面后暴露三个视觉问题：

1. **小图巨幅放大**：微缩图标/占位图（如 1×1、20×6、32×32、50×50）被放大 2~117 倍铺满，模糊失真；
2. **异形图暴力裁切**：横幅/装饰条（16:1、13.5:1）与方形图在 1.625:1 的缩略图区内只剩中间一条，
   信息几乎全部丢失；
3. **透明图透底**：半透明 PNG/SVG 直接透出占位层的彩色渐变 + 网格背景，观感脏乱。

封面 URL 由宿主提供、资产转码归宿主（ADR-0027），但「同一 URL 在不同卡片布局下如何呈现」是
Engine 的展示职责。Engine 无法预知图片内容，但可以在加载完成后读取图片**自然尺寸**，与缩略图容器
尺寸比较，按明确的阈值决策适配方式——这是纯展示投影，不改变 ADR-0040 的契约与宿主边界。

## 2. 决策

1. 封面 `<img>` 加载完成后，按「容器尺寸 vs 图片自然尺寸」计算两个指标并决策适配方式：
   - **放大倍数** `upscale = max(容器宽/自然宽, 容器高/自然高)`：`> 1.5` 时改 `contain`
     （完整显示、不放大、居中），避免小图模糊铺满；
   - **宽高比偏差** `aspectMismatch = |自然宽高比 - 容器宽高比| / 容器宽高比`：`> 0.35` 时改
     `contain`（不裁切），避免横幅/方形图只剩局部。
   两者都不超阈值时保持 `cover`（正常照片类封面铺满裁切可接受）。
2. 决策通过缩略图容器上的 `data-material-cover-fit="contain"` 标记 + CSS 后代选择器生效
   （`object-fit: contain`），不写内联样式；`cover` 是缺省值，不写标记。决策只发生一次（load 时），
   无后续几何变化，符合无抖动规约。
3. 封面加载成功后（无论 cover/contain），缩略图占位层（彩色渐变 + 网格 + 图标）整体收起：底色切换为
   中性深色（浅色主题对应中性浅色），网格与图标隐藏/淡出，透明图不再透出彩色占位背景。
4. 阈值与行为是展示启发式，不进任何契约：`cover` 字段校验、manifest 语义、catalog 身份与宿主边界
   与 ADR-0040 完全一致；官方物料与既有探针（320×200 封面，宽高比与容器一致）行为不变。
5. 图片加载失败仍按 ADR-0040 移除图片、恢复占位层；自适应决策不引入新的网络行为（不预取、不重试、
   不代理、不二次请求），不改变 `materialLibraryState`、宿主动作或卡片可用性。
6. 非目标维持 ADR-0040：Engine 不提供服务端缩略图/转码（归宿主 ADR-0027）；需要统一裁切出图的宿主
   应在自己的资产链路上生成缩略图。

## 3. 非目标

- 服务端缩略图生成、转码、缓存（ADR-0027：归宿主）。
- 感知图片内容（人脸/主体检测）、按内容裁切或居中偏移优化。
- 动态响应容器尺寸变化（决策仅一次）；hover/搜索等状态不改变适配方式。
- 修改 `cover` 字段契约、校验规则或 manifest 语义。

## 4. 结果

- 小图/异形图封面完整可见、不再模糊铺满或只剩局部；透明素材底色干净，卡片观感一致。
- 照片类封面（尺寸充足、宽高比接近容器）保持铺满裁切，视觉密度不损失。
- 全部行为是加载后的一次性展示决策，无抖动、无新增网络请求，官方物料与既有断言不受影响；
  实现、测试与验证由专项 Spec 保护。
