## 2. 编辑器界面

### 2.1 三栏结构（与 LIGHT CHASER 的根本差异）

| 维度 | GoViewPro | LIGHT CHASER |
| --- | --- | --- |
| 常驻面板占宽 | 68 + 370 + 380 = **818px** | 46 × 2 = 92px |
| **画布可用宽度** | **57%** | **95%** |
| 面板形态 | 常驻，挤压画布 | 浮层，覆盖画布 |

### 2.2 顶栏（高 62px）

```
[商品] GoViewPro [PRO]  [搜索组件 Ctrl+K]   [🔔][帮助][产品][头像▾][保存][预览][发布]
```

- 搜索是**全局**的（Ctrl+K）
- 右上角有**商品/会员入口**（商业化心智前置）
- 「保存」是显式按钮，不是自动保存状态

### 2.3 左侧（68px 图标条 + 370px 展开面板）

| 面板 | 内容 |
| --- | --- |
| 组件库 | **分类导航**：顶层 9 类 → 二级分组 → 组件（图表类可再分出子类，三级以下未逐层展开） |
| 收藏 | 收藏的组件 |
| 图层 | 图层树，可拖拽排序 |
| 页面 | 页面管理 |
| ~~数据池~~ | ~~项目级数据源，多组件共享~~ **（未核实，入口未找到，见第 11 节）** |
| 资源存储 | 上传的图片/视频 |
| AI 面板 | 「接下来做什么?」+ 输入框 |

**「数据池」未核实**：此前文档把它列为 GoView 特有功能，但本轮在「数据」tab 与左侧入口中均未找到。在确认之前，不应据此与 LIGHT CHASER 做对比。

### 2.4 右侧属性面板：**4 tab × 4 竖排大类**

```
[定制 ✨]  [动画 🖌]  [数据 📊]  [事件 ⚡]
```

**「定制」tab 内部还有第二级导航** `[实拍]`：

```
┌──┐
│图形│  ← 组件特有配置
│形状│  ← 全通用：3 轴旋转 / 双轴倾斜 / 双轴缩放 / 裁切
│滤镜│  ← 全通用：7 参数 + 混合模式
│高级│  ← 全通用：事件穿透 / 容器进出 / 钉固 / 悬浮 / JSON 编辑
└──┘
```

**这是关键结构**：4 个竖排大类里**只有「图形」是组件特有**，另外三个全通用。

### 2.5 画布

- 标尺 + 20px 点阵网格
- 底部页面条：页面 1 + ⋮ + 新增
- 缩放：百分比输入 + 适应 + 锁比例
- 悬浮工具条：导航 / 图形 / 文本三组

**单击选中，右侧面板立即显示配置**（不像 LIGHT CHASER 要双击）。

## 3. 「定制」tab 的四个大类

### 3.1 常驻区（不折叠）

```
组件ID  id_xxx                ● 录制
名称    [柱状图]              3 / 20
基础    38 X    355 Y    [⚓][⏱]
        560 W  🔗 241 H    0 °
颜色    [渐变条：青-紫-粉-紫-青]   [✎][🗑]
对齐    [6 图标]
```

**「颜色」是一行渐变条**，直接展示当前渐变，不用点开。比 LIGHT CHASER 的"色块 + hex"直观。

### 3.2 「形状」大类（全通用）`[实拍]`

```
旋转°
  Z轴(平面) - 旋转   [⏺][0][−+]
  X轴 - 旋转         [⏺][0][−+]
  Y轴 - 旋转         [⏺][0][−+]
倾斜°
  X轴 - 倾斜         [⏺][0][−+]
  Y轴 - 倾斜         [⏺][0][−+]
缩放
  X轴 - 缩放         [⏺][1][−+]  [🔗]
  Y轴 - 缩放         [⏺][1][−+]
启用裁切  [?]                [开关]
```

**7 个变换参数 + 裁切**。每个都是滑块 + 数值步进双形态。

**对比 LIGHT CHASER 的「基础」tab**：LC 有 3 轴旋转 + 透视 + 双轴倾斜 + 原点；GoView 有 3 轴旋转 + 双轴倾斜 + **双轴缩放**。

**到底确认**（`[实拍]`，读取完整 DOM 文本）：该面板只有上述 9 个字段 + 启用裁切，**无透视、无原点**。滚动容器溢出仅 8px，不是更多字段。

### 3.3 「滤镜」大类（全通用）`[实拍]`

```
启用          [开关 OFF]
色相          [彩色渐变滑条]   值: 0deg   底色 [■]
饱和度        [蓝色滑条]       值: 100%
对比度        [蓝色滑条]       值: 100%
亮度          [蓝色滑条]       值: 100%
透明度        [蓝色滑条]       值: 100%
高斯模糊      [0][−+]         值: 0px
混合 [?]      [正常 ▾]
```

**比 LIGHT CHASER 多的两个**：

1. **色相用彩色渐变滑条**——拖时直接看到颜色变化，不用记角度
2. **「混合」= `mix-blend-mode`**——LC 完全没有

每个参数还有**实时值标签**（`值: 100%`）。

### 3.4 「高级」大类（全通用）—— LIGHT CHASER 完全没有这一层 `[实拍]`

```
事件穿透   启用 [开关]
           事件将穿透到下方图层的组件，【远程页面】除外

容器超出   [请选择 ▾]
           滚动条处理（默认不处理）

钉固       启用 [开关]
           屏幕滚动时，组件固定在屏幕当前位置

悬浮样式   启用 [开关]
           鼠标悬浮变成小手

配置编辑   [点击编辑配置]    ← 蓝色
样式编辑   [点击编辑样式]    ← 粉色
```

| 字段 | 底层 |
| --- | --- |
| 事件穿透 | `pointer-events: none` |
| 容器超出 | `overflow` |
| 钉固 | `position: fixed` |
| 悬浮样式 | `cursor: pointer` |
| 配置编辑 | JSON 配置编辑器（标题「JSON 配置编辑器」，底部警示「有些配置改动可能导致组件无法正常使用」，按钮「关闭 / 保存」）`[实拍]` |
| 样式编辑 | 「样式配置编辑器」，JSON 编辑框默认 `{}`，底部示例 `{ "backgroundColor": "red" }`，提示「修改不了时请用全局样式」，按钮「关闭 / 保存」`[实拍，用户提供截图]` |

**「事件穿透」的说明写了例外**：「【远程页面】除外」——踩过坑才写得出来。

**LIGHT CHASER 做不出"不挡点击的装饰元素"**，因为它没有这一层。

### 3.5 「图形」大类：组件特有

**柱状图（一级 5 组 + 2 个系列）**：

```
▶ 渲染器   ▶ 容器   ▶ X轴   ▶ Y轴   ▶ 图例
▶ 柱状图-1  （系列，可删）
▶ 柱状图-2
```

> 字段明细见第 13 节。此前写作「7 组」，是把两个系列也计入了分组，已更正。

**饼图（3 组）**：

```
▶ 渲染器   ▶ 图例   ▶ 饼图配置
    类型 [环形图 ▾]
    [○] 动画  开启（将自动隐藏图例）
    ⓘ 无鼠标点击图例场景时，可强行打开图例
    图形  40%/65% 内圈外圈   50%/60% X轴中心/Y轴中心
    标签  [●]展示标签 [●]引导线   外侧▾   列名/百分比▾
    字体  14  #D8EFFFFF
```

**文字（2 组）**：

```
▶ 信息   → 文字内容 / 链接（http:// / 请输入 / 跳转）
▶ 样式   → 文字/字体/颜色/字号/粗细/X轴内边距/Y轴内边距/
           水平对齐/垂直对齐/文本方向/换行规则/字间距/倾斜/边框
```

**「渲染器」只有图表有**（只有图表需要选引擎）。
**「系列」柱状图有**（多系列），饼图没有。
**饼图的「动画」开关带副作用说明**：「开启（将自动隐藏图例）」+ 绕过方式。

| 入口 | 内容 |

| 功能 | GoViewPro | LIGHT CHASER |
| --- | --- | --- |

## 6. 「数据」tab（三步骤）`[实拍]`

```
[静态数据] [动态接口] [公共接口] [AI解析]

① 数据映射
   ┌─────────┬──────────┬────────────┐
   │ 源字段   │ 映射      │ 状态&过滤   │
   ├─────────┼──────────┼────────────┤
   │ product │ [product] │ 图表分...   │

   └─────────┴──────────┴────────────┘

   [开关] 字段超限时变色 / 闪烁 / 提示音

   [编辑] [导入] [下载] [?]
```

**三步骤，不是两个**。最前面是**数据映射**（三列表格），比 LIGHT CHASER 的「X字段/Y字段 两个下拉」精细得多。

## 7. 「事件」tab：交互编辑器（四栏表单）

```
┌──────────────────────────────────────────────────────────┐
│ 交互编辑器           组件 [文字 ▾]  [⌨ 快捷键]  [×]      │
├──────────────────────────────────────────────────────────┤
│ [事件 📄]  [交互1 - 单击 ×]  [+]                          │
├───────────┬──────────────┬────────────────────┬──────────┤
│ 类型(7)   │ 执行动作(15+) │ 动作配置            │ 预览     │
└───────────┴──────────────┴────────────────────┴──────────┘
```

**事件类型 7 种**：单击 / 双击 / 移入 / 移出 / 请求数据 / 全局变量改变 / 定时执行

**条件过滤**（可选）：`async filter({ dataset, eventData }) { return true }` —— 任意 JS，可 await

**执行动作 5 类 15+ 种**：

| 分类 | 动作 |
| --- | --- |
| 显隐 | 显示 / 隐藏 / 显隐切换 / 弹窗显示 |
| 动画特效 | 设置 / 变换 / 清除 / 滤镜 |
| 跳转 | 大屏页面 / 新地址 |
| 数据请求 | 触发组件请求 / 自定义请求 / 设置全局变量 |
| 组件 | 更新配置 / 修改数据 |

**三层一对多**：组件 → 多事件 → 多动作 → 多目标组件（动作的目标组件**可多选**）

**与 LIGHT CHASER 的根本差异**：

| | GoViewPro | LIGHT CHASER |
| --- | --- | --- |
| 形态 | 四栏表单 | 节点图 |
| 条件 | JS 函数 | JS 函数（节点内） |
| 数据源 | 组件属性 | **节点**（可连线） |
| 复杂度分布 | 集中在表单 | 集中在连线 |

## 8. 页面配置 `[实拍]`

未选中组件时显示：

```
宽度 1920 / 高度 1080
[缩略图]
背景颜色   #232324
应用类型   [应用背景 ▾]  [清除背景]
适配方式   [📱][💻][🖥][📐]
控件组件主题 [跟随全局主题 ▾]

切换动画 ⓘ  ›     网格布局 ›     滤镜 ›

[主题 🎨]  [全局样式 🔤]  [全局脚本 </>]

自定义颜色 [+]
[明亮]   [色块×5]
[暗淡]   [色块×5]
[马卡龙] [色块×5]
```

**三个重要功能**：

1. **「全局样式」/「全局脚本」** —— 页面级 CSS/JS 注入 `[实拍]`：全局样式为「样式资源」（添加）+「CSS 代码」（编辑代码，默认「暂无内容」）；全局脚本为「脚本资源」（添加）+「初始化代码」（编辑代码，默认「暂无内容」）。两者当前为空。
2. **页面级「滤镜」**（和组件级是两层）
3. **主题按「明亮/暗淡/马卡龙」三档 × 5 色块**（比 LC 的 7 套 × 6 语义位更轻）

## 10. AI（场景卡片式）

## 13. 图表组件的内部字段（柱状图，实拍）

> 方法：从组件搜索加入「柱状图」（组件 ID `id_1bn8r2y5oqps00`），选中后逐个展开 Naive UI 折叠面板（`.n-collapse-item`）读取字段。折叠组都是 `cursor: pointer`，可以直接点开。
> 注意：读取「已展开」组时会把之前展开过的组一起带出，下表已去重。

**「定制」tab 的一级分组**：基础、颜色、对齐 / 图形、形状、滤镜、高级 / 渲染器、容器、X轴、Y轴、图例 / 柱状图-1、柱状图-2（系列）。

| 分组 | 字段 |
| --- | --- |
| **渲染器** | 全局：svg / canvas 二选一；当前：svg / canvas / inherit（继承）三选一 |
| **容器** | 距离：左侧 10%、右侧 10%、上侧 60、下侧 60（比例与像素混用） |
| **X轴** | 单位、名称；颜色（#B9B8CE）、大小 12、偏移量 0；标签展示；轴线：颜色、粗细 1、位置 顶部/底部；对齐零、反向；刻度：展示、长度 5、粗细 1；分割线：展示、颜色 #484753、粗细、类型（实线） |
| **Y轴** | 同 X 轴，位置选项为 **左侧 / 右侧** |
| **图例** | 图例文字（颜色 #B9B8CE、大小 12、位置 居中）；图例位置：x 轴方向（靠上）/ y 轴方向；方向：水平 / 垂直；图例形状：圆形等；图例大小：宽 15、高 15 |
| **柱状图-1 / -2**（系列） | 图形：宽度 10、圆角 5、启用渐变色；标签：展示标签、大小 12、颜色 #fff、位置 上/左/右/下 |

**与「基础 / 样式」的关系**：图表的渲染与坐标轴全部收在「定制」tab 的图形相关分组里，「形状 / 滤镜 / 高级」是全通用的（见第 3 节）。

**结构特征**：
- 每个坐标轴都是完整的"标签 + 轴线 + 刻度 + 分割线"四段结构，与 LIGHT CHASER 的"X轴/Y轴"在字段粒度上接近，但 GoView 把**位置选项放在轴的分组内**，而不是在"基础"里。
- 系列（柱状图-1/-2）单独成组，说明图表是"多系列 + 独立标签"模型。
- 「渲染器」的 svg/canvas 切换是 GoView 独有的渲染层选择，LIGHT CHASER 未见对应项。

**未覆盖**：「数据」tab 中图表的数据字段映射（X/Y 字段）与「事件」中图表的可交互事件，本轮只读了「定制」。
