# Designer 工作台设计移植（顶栏 chrome 与视觉基座 → 表单控件 → 面板与引擎独有面）

> 状态：生效中
> 依据：[ADR-0088](../../decisions/ADR-0088-designer-workspace-chrome-and-visual-base.md)、[ADR-0079](../../decisions/ADR-0079-designer-workbench-shell-and-chrome.md)（其顶栏/状态栏非目标由 ADR-0088 取代）
> 设计权威（只读）：OpenDesign 项目 `60a33a0e-b528-48a6-8e0c-b7e4e775b0f5` 的 `index.html`（工作台）、`form-controls.html`（检查器表单控件）与 `feature-coverage.md`；不修改该目录。

## Requirements

把 OpenDesign 原型的 UI 逐批替换为引擎真实实现：视觉、布局与控件形态以原型为唯一权威；替换发生在视觉层，引擎能力集合只增不减。原型定义了的界面对齐原型；原型未定义的引擎独有面（蓝图工作台、数据工作台、错误控制台、对话框、画布覆盖层等）按设计体系推导并复核。

引擎侧实现栈不变：原生 TypeScript + Shadow DOM + 分层 CSS；公共 `--base-screen-designer-*` Token 覆盖面不变（值可重定义）；对宿主可见的默认行为变化（默认主题、快捷键、菜单结构）必须记录进 ADR 与 changeset。

## 批次

- **批 1（已完成，2026-10-12）视觉基座 + 顶栏 chrome**：
  - 令牌层重建为原型 Vercel 体系：浅色缺省、黑夜覆盖、34 公共 Token 覆盖面不变、对比度契约令牌以解析值烘焙（浅色 success/warning 按契约收档）。
  - 顶层菜单栏（文件/编辑/视图/工具，原「更多」子菜单提升）、居中工作模式分段控件、搜索触发器（Ctrl/Cmd+K）与动作行重排、发布按钮反转实底 CTA。
  - 状态栏指标并入右段；工作区工具栏 40px 列头 + 28px 按钮 + 缩放读数复位与「缩放至适应」；标尺 22px。
  - 顶栏样式单一维护点收敛（删除 `designer-workbench-blueprint-toolbar.css` 的重复副本），菜单悬停中性化、阴影即描边收边。
  - harness 与单测同步（有意更新的断言逐条列在提交信息与交付报告）。
- **批 2（已完成，2026-10-13）表单控件体系**：按 `form-controls.html` 重做/补齐检查器控件（日期/时间、步进器、悬浮提示、绑定字段选择器为当前缺口），统一控件高度、焦点态、校验态、禁用态。
  - 2a 悬浮提示（完成）：`[data-tip]` 单例浮层替代原生 `title`（420ms 延迟、键盘聚焦即时、Esc 抑制重弹、禁用控件坐标扫描兜底、贴边翻转/左右夹取、caret、`aria-describedby` 接线）；引擎内 `title` 全量迁移（含动态赋值与物料卡类型行），harness 断言把「零 title + 延迟浮现 + 位置/翻转 + Esc 抑制 + 键盘聚焦」钉死。
  - 2b 控件基座（完成）：控制高度 32→30px、描边改 `elev-ring` 阴影（无真实 border）、悬停/聚焦/错误/成功/禁用/只读/混合四态重写、`.btn` 契约（悬停只换底色、按压不缩放）、主档反转实底、图标按钮 28px、复选框补 `:indeterminate` 半选与 `data-mixed` 虚线段。连带修复：物料卡被控件高度固定值压扁、变量行动作条与上下文行的堆叠顺序。
  - 2d 步进器（完成）：plugin-core 描述符词汇新增 `stepper`（要求数字 schema 且双边有界，失败关闭），引擎渲染 − / 可键入值 / + 三段式并在边界禁用与交接焦点；harness 语义图表物料「字号」接线，harness 断言钉死外壳几何、步进、夹取与文档写回。有意偏离：值位是可键入输入而非展示用 span（不牺牲键入精确值的能力）。
  - 2e 日期选择（完成）：`datefield` = 输入框 + 锚定触发器 + 自绘日历（周一起始 6×7、今天/选中/外月三态、方向键/PageUp-Dn/Home-End、今天按钮、贴底翻转、域外点击与 Esc 关闭），接入数据集参数编辑器 `valueType: 'date'`；harness 断言钉死外壳、标题/星期/选中态与选日写回。修出的缺陷：shadow 树外的 document 捕获监听里 `event.target` 被重定向成宿主，弹层在真实点击时误关——改用 `composedPath()[0]`。时间列弹层暂不落地：数据集值类型只有 `date`，无消费者（出现消费者时按同一外壳补时/分双列）。
  - 2f 绑定字段选择器（完成）：限额多选改为「触发器芯片 + 计数 + 自绘弹层（类型标签/勾选/达上限禁用/底部提示）」，芯片 × 与 Backspace 复用既有绑定动作，弹层开合跨面板重渲染保持；harness 物料 `harness.dataset-ranking` 的 measures 改为 `maxFields: 2` 以进入验收路径，断言钉死外壳、移除、还原与 Esc 关闭。
  - 2g 分段控件统一（完成）：画布缩放、数据源、检查器密度、数据集编辑器四处自制分段收敛到 controls 层单一形态（workspace 底 + `elev-ring`，选中 = 悬停档底 + 强调文字，黑夜更深一档），上下文只保留列数差异。
  - 2c 自绘下拉选择（裁定并入批 3）：原生 select 已在 2b 按原型重基；自绘 listbox（勾选项、键盘导航、隐藏原生 select 承载值）与检查器/数据集面板的整体排布同批落地，避免二次返工同一批 DOM 与断言。
- **批 3（已完成，2026-10-13）面板体系**：左栏（素材库/图层/变量）、检查器分节与控件排布、命令面板、菜单浮层与提示条细节对齐原型；原 2c 自绘下拉选择随批落地。
  - 3b 命令面板与提示条：面板卡改阴影描边（`elev-ring + shadow-overlay`，去掉 1px 描边）、kbd 徽标对齐 `.kbd-badge`（workspace 底 + 内收边 + 11px 等宽）；提示条改覆盖层卡片（`surface-overlay` 底、8px 圆角、`elev-ring + shadow-float`、10/12 内边距、340px 宽、距状态栏 16px），语义色只染图标（新增 `check-circle` / `x-circle`），关闭按钮转幽灵档。
  - 3c 左栏：切换条收敛到原型 .rail-tabs（raised 轨 + 内收边分隔、8×2 内边距、44×60 竖排 tab、选中 = control-active 胶囊 + 收边 + 600 字重 + 强调色图标、宿主分组上缘留白 + 分隔线）；列头带 40px + 8px 内边距，计数改 control-active 药丸，新增归属标签（`BUILTIN` / `HOST` / `PLUGIN`，随工作模式与分组更新）；素材卡圆角 8、gap 4、悬停中性（control-hover + 强收边 + 浮动影）、缩略图改中性底 + `canvas-grid-line` 网格纹理（色相渐变退役）；素材筛选、图层行（40px/主选 = accent 淡底 + accent 收边/次级 = 中性按下档）与网格间距（10px）对齐原型。
  - 3d 检查器：标签页改左对齐浅胶囊（30px 高、选中 = control-active + 收边 + 600）、内容列内边距 8/12/24、分节标题改 13/600 一级文本 + 发丝拖动线。
  - 3e 自绘下拉（原 2c）：`enhanceDesignerSelect` 增强既有原生 select（触发器 + 自绘弹层 + 1px 隐藏原生元素承担取值与 change），迁移描述符枚举字段、画布背景类型/适配方式、数据集单选角色绑定；键盘 ↑↓/Enter/Esc、禁用项跳过、贴底翻转、域外点击关闭自回收。迁移保持既有值载体契约，调用点只改 appendChild 目标。
- **批 4（未开始）引擎独有面**：画布标尺/选区/辅助线、蓝图工作台、数据工作台、错误控制台、对话框、宿主/插件面板承载面按设计体系推导；清理色板/快样式/材质封面的手工波及文件。
- **批 5（未开始）收尾审计**：全 `browser/` 双主题截图矩阵核对「旧视觉残留清单」归零；旧视觉令牌与旧样式删除干净；文档收口，本 Spec 归档。

## 验收

批 1：`pnpm verify:m0`、`pnpm verify:browser` 全绿；harness 双主题 1920×1080 与紧凑视口截图与原型 `color-fix-check.png`（浅）/`dark-*.png`（深）人工比对；菜单键盘/悬停/翻转、主题切换、面板折叠、缩放 fit/reset、Ctrl+K 实机可用。替换完成：引擎全部界面双主题与设计体系一致、旧视觉零残留、截图矩阵覆盖全部工作台区域。

## 回滚

视层替换可整批回滚：令牌与样式集中在 `packages/engine/src/browser/styles/`，顶栏结构集中在 `designer-workspace-markup.ts` 与其 controller；宿主如只需恢复旧观感可钉 `theme="dark"`（默认主题翻转的单点回退）。批 2 之后每批独立回滚，互不回填。
