# Color Palette Gradient From Solid Spec

> 归档：2026-08-30（已完成）
> 状态：生效中
> 日期：2026-08-16
> 依据：[ADR-0057](../../../decisions/ADR-0057-color-palette-gradient-from-solid.md)

## 1. 目标

统一三段式调色板从单色切换到渐变模式时，渐变首帧继承单色色系（不再是无关的
默认黑→白）；已定制的渐变色标在模式往返中保留。字段值格式、序列化与公共契约
零变化，纯 Designer 控件交互行为增强。

## 2. Requirements

### R1：切换派生（单色 → 渐变）

从单色模式切换到线性/径向渐变时，若当前色标为内置默认（恰好 `#000000` 0% 与
`#ffffff` 100% 两个色标），SHALL 按单色派生色标：起点 = 单色（规范化小写，
保留 alpha 通道），终点 = 同色系向白混合 45% 的提亮；提亮与起点无区分度时
（起色接近纯白）改为向黑混合 35% 的加深；派生结果保证终点与起点不同。
`transparent`/不可解析单色 SHALL 不派生（保持默认色标）。

### R2：保留自定义色标

非默认（作者已定制）的渐变色标 SHALL 在模式往返切换中原样保留；只有恰好等于
内置默认的色标组才触发 R1 派生。线性 ↔ 径向互切 SHALL 保持色标与几何参数。

### R3：派生边界

- 派生只发生在交互切换路径（mode change handler）；文档值本身为渐变的解析
  路径 SHALL 不受影响（按文档色标呈现）。
- 派生后的渐变值 SHALL 走既有序列化格式与提交通道（恰一条历史），可 undo。
- 派生同一字段只发生一次：派生结果进入草稿缓存后即为「已定制」语义。

### R4：质量与验证

- 聚焦单元测试 SHALL 覆盖：派生算法（常规色/纯黑/纯白/短十六进制/带 alpha/
  transparent 不派生）、切换派生（单色 → 线性与径向、DOM 值同步序列化）、
  自定义色标保留、渐变互切保留、解析路径不受影响。
- 真实 browser harness SHALL 验证：单色模式下设置色值后切到线性渐变，
  首帧色标起点为所选色值。
- 交付前 SHALL 通过格式化、聚焦检查与 `pnpm verify:m0`（`verify:browser`
  手动跑通）。

## 3. 非目标

- 渐变预设色板、HSL 色相算法、派生比例配置化。
- 色标增删/位置编辑/草稿缓存/序列化契约变更（ADR-0050 既定语义）。
