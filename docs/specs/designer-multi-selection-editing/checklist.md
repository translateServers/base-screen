# Designer Multi Selection Editing Checklist

> 状态：已完成（2026-08-16，`pnpm verify:m0` 与 `pnpm verify:browser` 全绿）

## 行为（R1-R4）

- [x] 多选检查器显示批量几何区（宽度/高度/旋转），无 X/Y。
- [x] 多选检查器显示样式交集区；混合类型无交集时只显示几何区。
- [x] 批量样式控件与单选一致（非 color 常规控件、color 三段式调色板含渐变）。
- [x] 值不一致时输入框显示焦点组件值；编辑后应用到全部选中组件。
- [x] 一次编辑恰产生一条历史记录；undo/redo 往返正确。
- [x] 锁定成员被跳过、全部锁定或无选中时字段禁用；单选事务通道不受影响。

## 质量（R5）

- [x] common 层有聚焦单测：交集计算（同类型/混合/空）、锁定跳过、schema 校验、事务形状。
- [x] 批量颜色（含渐变字符串）提交有聚焦单测。
- [x] 真实 browser harness 断言多选批量改宽度/字号/颜色生效于全部选中且恰一条撤销记录。
- [x] `pnpm verify:m0` 通过，ADR/Spec 索引与能力基线已同步。
