## 1. 背景

Base Screen 是嵌入宿主的大屏设计器基座。图片上传、存储、素材目录归宿主；设计器只保存
`host-resource` 资源身份。宿主需要一套素材库与选图页面，满足：

> **2026-10-26 更新**：示例当前把公共素材上传/删除放在宿主后台 `#/assets`；设计器左栏只做
> 消费 + 临时上传（绑定当前大屏）。本 brief 的 P1 上传/删除与 T4 删除流程作为历史设计参考，
> 当前实现以 `examples/README.md` 的「宿主素材库与图片选择」为准。

- 在宿主左栏浏览/搜索/上传素材，点击或拖拽插入画布；
- 替换已选中的图片组件，或把素材设为画布背景；
- 从组件检查器打开同一个图片选择器；
- 删除被屏幕引用的素材时给出明确阻断与引用信息；
- 视觉上与 Base Screen 设计器一致，不引入第二套设计语言。

交互优先：先确认用户任务、状态与动作位置，再做视觉。参考 DataV 的素材库/图片选择、Figma Assets
面板与蓝湖的资源管理；不要只换皮或堆卡片。

## 2. 本轮 OpenDesign 交付物

1. **低 fidelity 交互流**：每个用户任务的步骤、状态、动作、失败出口。
2. **高 fidelity 页面**：素材库左栏、图片选择器、画布背景流程；在线物料管理页可选。
3. **可交互原型**：覆盖第 5 节状态矩阵；可点击、可切换状态、可键盘操作。
4. **设计说明**：布局尺寸、交互决策、未采纳方案、仍需产品确认的问题。

原型是中间产物；最终实现必须落到仓库代码并验证，不以原型交付收尾。

## 3. 页面范围

### P1. 宿主素材库左栏

- 嵌入 `leftPanelGroups` 的宿主命名 slot；默认仅 Canvas 模式。
- 面板宽度 240–320px；可随宿主布局拉伸，但内部网格与操作条不抖动。
- 结构建议：头部（标题 + 上传/刷新）、搜索框、筛选/排序（可选）、素材网格、底部选中操作条。
- 素材卡：固定宽高比缩略图、名称/尺寸/大小（可选）、加载占位、失败占位、选中态。
- 操作：上传（按钮 + 拖入面板）、点击选中、拖拽插入、插入画布、替换选中图片、设为画布背景、
  删除（受引用保护）、复制资源 ID（可选）。
- 空态、搜索无结果、加载中、加载失败、无权限、上传中/失败都要有明确出口。

### P2. 图片选择器

- 由组件检查器「选择素材」或画布背景按钮触发；宿主自己的弹层或侧滑，不进入 Engine Shadow DOM。
- 结构建议：标题 + 当前素材摘要、搜索、素材网格、右侧/底部详情（缩略图、名称、尺寸、大小、格式）、
  取消/确认；画布背景目标额外显示 fit（`cover` / `contain`）。
- 打开时选中当前素材（若有）；支持键盘上下左右移动、Enter 确认、Esc 取消。
- 空态、加载、错误、无权限、上传入口（可选）与素材库面板一致。

### P3. 画布背景流程

- 从画布属性面板的背景按钮触发，复用 P2 选择器。
- 选中素材后确认：提交 `url` 变体 + `backgroundImageFit`；立即生效，可撤销。
- 不提供“应用”二次按钮；不要跨滚动提交。
- 当前背景 URL 不可用时显示占位与“重新选择”。

### P4. 在线物料管理页（可选，宿主侧）

- 仅当宿主没有现成管理页时设计：物料包列表、构建/发布/审核状态、更新/回滚、引用数与影响范围、
  加载失败诊断、破坏性变更阻断说明。
- 与素材库保持同一套表格/状态/诊断视觉语言；不把物料包版本号、URL、凭证显示在面向终端用户的页面。

## 4. 用户任务与交互流

### T1. 上传并插入图片

1. 用户点击上传或把文件拖入素材库面板。
2. 显示逐文件进度、取消、失败重试；类型/大小不合法时立即说明原因。
3. 上传成功后素材出现在网格顶部并自动选中；用户可拖拽到画布，或点击“插入画布”。
4. 插入后设计器选中新图片组件；素材库保持当前筛选与滚动位置。

### T2. 替换已选图片

1. 用户在画布选中一个图片组件。
2. 素材库底部操作条出现“替换选中图片”；选择素材后点击替换，或用素材卡的上下文菜单。
3. 替换立即生效，保留组件几何、样式、层级与动画；给一次轻量反馈，可撤销。
4. 选中的不是图片组件时，替换动作禁用并说明原因。

### T3. 设为画布背景

1. 用户在素材库选中素材，点击“设为背景”；或在画布背景按钮打开选择器。
2. 选择 fit（`cover` / `contain`），确认后立即生效。
3. 背景切换不改变画布尺寸、标尺、选区或滚动位置。

### T4. 删除被引用素材

1. 用户对素材执行删除。
2. 宿主检查引用：被引用时阻断，显示引用数量与可用的“查看引用/前往屏幕”；不提供强制删除。
3. 未被引用时二次确认后删除；删除后网格位置稳定，不整屏重排。

### T5. 在线物料发布/更新/回滚（可选）

1. 管理员查看物料包列表与当前激活状态。
2. 构建/审核/发布；更新前显示影响的物料类型、引用数与潜在破坏性变更。
3. 发布后设计器不刷新即可用；失败显示诊断与回滚入口。
4. 破坏性变更（如 props/style schema 不兼容）必须阻断并说明需要迁移或发布新 type。

## 5. 状态矩阵

| 状态 | 触发 | 界面表现 | 主操作 | 禁止 |
| --- | --- | --- | --- | --- |
| initial loading | 首次打开 | 骨架网格，固定卡片尺寸 | 等待 | 空白闪烁 |
| empty | 无素材 | 说明 + 上传按钮 + 拖入提示 | 上传 | 只显示“暂无数据” |
| list ready | 有素材 | 网格 + 搜索 + 选中操作条 | 选中/拖拽/插入 | 卡片尺寸跳动 |
| searching | 输入搜索 | 搜索框 loading，旧结果保留到新结果到达 | 清除搜索 | 清空网格造成跳动 |
| no results | 搜索无命中 | 说明 + 清除搜索 | 清除搜索 | 隐藏搜索框 |
| selected | 选中素材 | 卡片选中态 + 底部操作条 | 插入/替换/设为背景/删除 | 用强调色表示选中 |
| uploading | 上传中 | 进度条/百分比、取消 | 取消 | 阻塞整个面板 |
| upload failed | 上传失败 | 失败原因 + 重试/移除 | 重试 | 静默丢弃 |
| unsupported type | 类型不允许 | 就地错误说明 | 更换文件 | 只弹 toast |
| oversized | 超过大小限制 | 显示限制值与当前值 | 更换文件 | 上传后再失败 |
| permission denied | 无上传/删除权限 | 只读态 + 原因 | 联系管理员/返回 | 隐藏整个面板 |
| image load failure | 缩略图/大图失败 | 固定占位 + 重试 | 重试 | 撑开布局 |
| replace target | 选中图片组件 | 底部操作条启用“替换选中图片” | 替换 | 替换非图片组件 |
| delete blocked | 删除被引用素材 | 阻断对话框 + 引用数/位置 | 查看引用/取消 | 强制删除 |
| delete confirm | 删除未引用素材 | 二次确认 | 删除/取消 | 直接删除 |
| picker open | 检查器/背景触发 | 当前素材选中 + 详情 + 确认/取消 | 确认/取消 | 遮挡到无法返回 |
| picker confirm | 确认选择 | 立即生效 + 可撤销 | 撤销 | 二次 Apply |
| background fit | 画布背景 | `cover` / `contain` 分段选择 | 确认 | 改变画布几何 |

## 6. 布局与尺寸

- 左栏面板：240–320px；头部 40px 列头高度与设计器一致；搜索与操作条不随滚动移出。
  列头与外层 12px 内边距由设计器宿主面板容器提供，宿主内容不要重复标题或再加一层留白。
- 素材网格：2–3 列自适应；卡片固定宽高比（建议 4:3 或 1:1），缩略图 `object-fit: cover`；
  加载/失败占位与卡片同尺寸，避免布局位移。
- 选择器：弹层（桌面）或侧滑（窄屏）；宽度建议 720–960px，最大高度不超过视口 80%；
  网格区域独立滚动，详情区固定；Esc/遮罩关闭前保留当前选择。
- 操作条：底部固定，主操作在右；删除等危险操作与主操作分开，使用 danger 语义。
- 拖拽：素材卡拖拽时显示轻量拖拽预览；进入画布显示可放置反馈；面板自身拖入显示上传覆盖层。

## 7. 设计令牌

以 `packages/engine/src/browser/styles/designer-tokens.css` 与
`tooling/verification/browser-harness/system.html` 为准。宿主页面使用自己的 CSS 变量副本，值与下列
令牌一致；不要直接引用 engine 私有 Shadow DOM 样式。

| 类别 | 浅色 | 深色 |
| --- | --- | --- |
| workspace 表面 | `#f4f4f4` | `#1e1e1e` |
| panel 表面 | `#fcfcfc` | `#0f0f0f` |
| raised 表面 | `#ffffff` | `#080808` |
| control 表面 / hover / active | `#f7f7f7` / `#ececec` / `#e7e7e7` | `#161616` / `#2a2a2a` / `#323232` |
| overlay | `#ffffff` | `#262626` |
| canvas | `#efefef` | `#282828` |
| 文本 primary / secondary / muted / disabled | `#171717` / `#4d4d4d` / `#666666` / `#808080` | `#f5f5f5` / `#b7b7b7` / `#aeaeae` / `#7d7d7d` |
| 边框 subtle / default / strong | `rgb(23 23 23 / 10% / 15% / 16%)` | `rgb(245 245 245 / 10% / 15% / 16%)` |
| accent / accent-text | `#0070f3` / `#145ec2` | `#5297fc` / `#609ffc` |
| focus ring | `#0070f3` | `#5297fc` |
| success / warning / danger | `#1d9746` / `#a48025` / `#dc2626` | `#4fcb6f` / `#e6b221` / `#fc675c` |

- 字体：Geist / Geist Sans 优先；字号 11 / 12 / 13 / 14 / 15 / 18px；字重 400 / 500 / 600。
- 间距阶梯：2 / 4 / 6 / 8 / 12 / 16 / 24 / 32px。
- 圆角：2 / 6 / 8 / 12px；控件圆角 6px；胶囊 999px。
- 控件高度：常规 30px，紧凑 28px；图标 16px；列头 40px。
- 动效：150ms `cubic-bezier(0.2, 0, 0, 1)`；强调 200ms。
- 交互面用“阴影当边框”：`0 0 0 1px rgb(0 0 0 / 8%)`（浅色）/ `rgb(245 245 245 / 15%)`（深色）；
  只有真正的分隔线用 `border`。
- 选中不是强调色：列表/网格选中用中性灰块 + 1px 中性收边；强调色只表示主操作、焦点与当前定位。
- 焦点环统一用 `--designer-focus-ring`，覆盖整行/整卡片命中范围，`outline-offset: -2px`。

## 8. 控件与交互模式

- 复用设计器已有的按钮、输入、下拉、勾选、开关、文本域与面板 chrome；不新增设计系统。
- 工具型、密度优先；不要营销式大卡片、渐变装饰、圆角气泡或大面积留白。
- 主操作每屏最多一个；危险操作使用 danger 语义并与主操作分开。
- 即时生效 + 可撤销：上传、替换、设为背景都不需要二次 Apply；撤销入口与设计器历史一致。
- 搜索去抖；加载时保留旧结果，避免闪空。
- 拖拽与点击是两条并行路径：拖拽插入，点击选中后通过操作条执行；双击可作为插入快捷方式。
- 键盘：Tab 顺序、方向键移动网格、Enter 确认、Esc 关闭；焦点环完整；不能用 hover 才显示关键操作。
- 文案中文、简洁、动作动词开头；不使用 emoji。

## 9. 无抖动与无障碍

- 卡片/缩略图固定尺寸与宽高比；图片加载前后不改变布局。
- hover/active 不改变几何、边框宽度或字号；用 `outline`/`box-shadow`/`transform` 表达状态。
- 网格与详情区各自滚动，滚动条轨道稳定；不要因为滚动条出现/消失让内容横向跳动。
- 主题切换原子更新 token，不逐属性闪烁。
- 对比度：正文与操作文字达到 AA；焦点环在两种主题下可见。
- 键盘可达全部操作；拖拽不是唯一路径；对话框有 `role="dialog"`、标题与焦点陷阱。
- 上传进度、错误、阻断删除等状态用 `aria-live` 或等价方式宣告。

## 10. 视觉禁区

- 不使用强调色表示“选中”；不把选中做成整片蓝色。
- 不使用大圆角卡片堆叠、玻璃拟态、彩色渐变背景来“提升高级感”。
- 不在宿主页面里复制 Base Screen 的 Shadow DOM 结构或私有类名。
- 不显示 URL、token、header、数据库信息；素材只显示名称、尺寸、大小、格式等展示元数据。
- 不新增版本号风格的标签（`v2`、`API v3` 等）；版本信息只作为内部构建 token，不面向终端用户。
- 不把删除保护做成“强制删除”二次确认；被引用就是阻断。

## 11. 评审清单

- 第 5 节状态矩阵是否逐项覆盖？
- T1–T4 是否各自有成功、失败、取消与空态出口？
- 拖拽、点击插入、替换、设为背景是否都有明确反馈？
- 选中态与焦点态是否可区分，且选中不使用强调色？
- 卡片加载/失败是否不改变布局？
- 240–320px 左栏与 720–960px 选择器是否都可用？
- 键盘能否完成选择、确认、取消、上传？
- 浅色/深色主题是否一致？
- 是否只用了现有令牌与控件语言？
- 是否有任何跨滚动提交、二次 Apply 或模式层可以删除？
