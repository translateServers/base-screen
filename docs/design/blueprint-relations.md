# 蓝图关系视图 · 设计说明

蓝图与画布是同一份 `ScreenDocument` 的两种表达：画布负责空间，蓝图负责语义与结构。本说明
记录作者面的信息结构、视觉词汇与交互约定；视觉权威是 OpenDesign 原型
`relationship-blueprint.html`（用户生成），实现落在引擎默认画布与三端示例宿主画布。

## 1. 信息结构

| 区域 | 内容 |
| --- | --- |
| 左侧 | 组件 / 关系 / 变量三个库；组件树按 `parentId` 缩进并显示出/入计数；关系按交互联动、数据共享、业务出口、语义关联、结构分组 |
| 中央 | 关系画布：组件、变量、业务系统节点与 relation / semantic / containment / dependency 边 |
| 右侧 | 选中节点/关系后的检查器；关系包含来源、事件、条件、效果、上下游与删除 |
| 底栏 | 节点与关系计数、校验问题、提示与缩放 |

## 2. 节点卡片

所有卡片 208px 宽、6px 圆角、`surface-raised` 底、卡片三层阴影（描边 + 近影 + 远影 + 内高光）。

- 头部 45px：20px 图标方块、两行文案（kind + 标题）、右侧出/入计数胶囊（变量不显示）。
  - 组件：`组件 · <materialType>`，标题为组件名；
  - 变量：`变量 · 静态`，图标用强调底；
  - 业务系统：`平台 · 业务出口`。
- 副行 21px：`materialType · componentId` / `variableType · variableId` /
  `${exitCount} 个业务出口`，等宽 9.5px。
- 变量值行 40px：`初值 <值>` + `N 写 / M 读`（不把初值冒充运行时当前值）。
- 端口行 28px：左侧事件/语义/结构名称，右侧 tag（事件 / 语义 / 结构 / 不可用），不可用行
  追加锁图标；行悬停底色为前景 4%。
- 结构摘要行 32px（仅容器与宿主提供的真实摘要）：`结构 · 子组件 N`，等宽 9.5px。
- 端口原点 8px：输出实心、输入空心；语义端口为 45° 实心菱形；结构端口为空心方块；
  不可用端口为虚线描边；24px 命中区。
- 输入端口位于卡片左侧垂直中心；输出端口对齐全宽 24px 命中区。

状态：

- hover：追加 `border-strong` 描边与外浮影；
- selected：1px 强调描边 + 3px 强调底光环；
- traced：48% 强调描边；failed：危险色描边；
- 空事件：显示「暂无可用事件」，组件仍可参与语义/结构/数据关系。

## 3. 连线与标签

| 类型 | 线 | 端点 |
| --- | --- | --- |
| relation（行为） | 1.5px 实线，secondary | 目标箭头 |
| semantic | 1.4px 虚线 7/5 | 两端圆点 |
| containment | 1px 虚线 1/5，55% 不透明 | 无端点 |
| dependency（读取） | 1.6px 点线，disabled 色 | 目标圆点 |

- 路由：输出口水平出线 → 在列间空隙折向目标纵向中心 → 水平入线，12px 圆角；反向/重叠时
  绕行下方，按边 id 哈希错开。
- hover / selected / traced / failed：`text-primary` / 强调 2.4px / 强调 2.2px / 危险色。
- 标签：22px 高贴纸，5px 圆角，overlay 底 + 描边与浮影；10px 等宽，带类型图标；最多 168px
  省略；悬停提色，选中强调描边，轨迹强调描边。
- 依赖（读取）标签在静止态隐藏，选中或轨迹命中时显示；关系/语义/结构标签常显。
- 标签位置优先落在连线中段，避开节点矩形与已放置标签；挤不下时回退到线上位置。

## 4. 布局

自动布局是会话默认值，不修改文档；拖动节点后写入 `blueprint.layout`，「自动布局」是显式
可撤销命令。

- 只读变量（没有写入关系）排在组件左侧，使读取依赖保持左→右；
- 有写入的变量排在组件右侧，承接写回；
- 组件按关系深度排序，宽画布 3 列、窄画布 2 列，列优先均衡；
- 业务系统节点在组件右侧（变量在左时）或变量列下方，单例；
- 画布 20px 点阵；适应画布预留底部模拟条高度，避免默认视图裁掉最后一行；
- 缩放渲染：图层固定按 2x 排版（CSS `zoom: 2`），实际缩放只改 `transform`：
  `translate(x/2, y/2) scale(zoom/2)`。缩放全程仅合成变换、不重排；卡片与文字使用 2x 纹理，
  最高 200% 时 1:1 清晰，低缩放时降采样；
- 视口提交使用实际发送的取整值，避免回传状态被再次采纳造成回跳；
- 缩放低于 0.62 时隐藏未选中/未轨迹标签。

## 5. 画布操作

蓝图沿用 Canvas 的工作台手势，避免切换模式后改变操作习惯：

- **平移**：按住空格 + 拖拽（任意起点，含节点/端口）；普通滚轮平移，`Shift + 滚轮` 水平平移；
- **缩放**：`Ctrl/⌘ + 滚轮` 以指针为锚点按 1.1 倍缩放；
- **选中**：单击节点/连线/标签选中，空白单击取消；`Ctrl/⌘ + 单击` 切换当前选中；
- **框选**：空白拖拽绘制选框；蓝图选择模型当前为单选，框选落在多个节点时取交集面积最大的一个，
  不会跨节点多选或成组拖动；
- **拖动**：节点头部拖拽移动，落位吸附 8px 并写回布局；空格拖拽不会移动节点；
- **键盘**：`Esc` 取消连线/关闭浮层/清除选中，`Delete/Backspace` 删除选中关系，`Ctrl/⌘ + 0` 适应画布。

宿主画布可自行实现手势，但应保持同一套语义（空格平移、普通滚轮平移、`Ctrl/⌘ + 滚轮` 缩放、
空白框选），否则会破坏作者在两个模式之间的肌肉记忆。

## 6. 作者流

1. **建立交互联动**：从组件事件端口拖到目标组件输入口 → 默认生成 200ms 淡入的显示关系；
   在检查器改效果类型（显隐/请求数据/设置变量/请求变量/业务事件/业务动作）。
2. **数据共享**：拖到变量生成 set-variable；从变量事件拖到下游组件表达订阅；组件读取变量
   由数据源参数自动生成 dependency 边与「N 读」计数。
3. **业务出口**：先从左侧「关系」库添加业务系统节点，再把组件/变量事件拖到宿主输入口。
4. **语义关联**：从组件底部的语义端口拖到另一个组件，默认「关联」，可在检查器改为详情、
   分组或下钻；无语义关系的组件仍可拖出语义端口。
5. **结构**：父子关系在画布/图层面板维护；蓝图中 containment 边只读，不可删除。
6. **条件**：检查器「条件表达式」添加变量条件；多条件效果通过多条同源关系表达，规则由
   连续同源同条件关系派生。
7. **问题**：工具栏校验入口只展示真实契约诊断；无问题时显示「校验通过」。

## 7. 宿主画布要求

宿主可用 slot 覆盖中央画布，但必须消费公开 `base-screen-blueprint-canvas-state` 并发出
`base-screen-blueprint-canvas-command`：

- 渲染组件/变量/宿主节点、事件与语义/结构端口；
- 发送 `relation:in` 作为目标 handle，`semantic:out` 作为语义来源 handle；
- 对关系/语义/结构/读取边给出可读标签或等价提示；
- 不读取 `blueprint.rules`，不依赖引擎私有 DOM；
- `commit-layout` 只写节点位置与视口。

三端示例画布（`examples/*/src/screen/blueprint-canvas.ts`）逐字共享，改一处必须同步三处。
