Finish the design-prototype port for the engine-only surfaces (design-port batches 4a-4b). The data workbench step list marks its current step with the neutral navigation tier — `control-active` surface, primary text, 600 weight, neutral position bar — instead of raw accent text that measured about 3.7:1 on the panel surface and failed AA; the data preview tabs adopt the inspector's light-pill tab language, and the static-data tab pressed state adopts the unified segmented-control tier. Opening the data workbench now also hides the canvas toolbar, rulers and canvas stage the way blueprint mode already does, so the canvas no longer paints under the opaque overlay, and closing restores it through the same resize path as mode switching. Canvas overlays are unified into the accent family: snap guides and persistent guides use the accent (persistent guides previously used the contrast-corrected warning olive, a status colour), measurement readouts use the contrast-safe `accent-text` token (5.6:1 light / 6.2:1 dark), and the canvas hover ring is a visible 45% accent ring rather than a 10% `accent-surface` wash that read as no feedback at all. Numeric sliders are redrawn in the prototype's value-control language — a 6px pill track plus a 14px custom thumb with a 2px surface-coloured ring — replacing native `appearance: auto` painting driven by `accent-color`, which also wires the `--designer-range-track` token declared but left unconsumed since the first batch. Dialog surfaces drop their real 1px border for the overlay family's shadow-as-border treatment. Cleanup: two tokens with no consumers are removed, the ruler canvas fallback literals move off the pre-port zinc greys, and blueprint panel CSS loses fourteen classes that no longer have DOM producers. Public API, tokens and document contracts are unchanged.
